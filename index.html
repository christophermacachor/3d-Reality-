Stage 1 — The Golden-Angle Spiral

the spiral is generated by the calculation · 137.5078° per step · radius ∝ √n

The spiral is computed. Each point is placed at the golden angle (137.5078°) and the radius grows as √n. The points are not hand-drawn; they are computed from the rule and rendered.

// Stage 1 — golden-angle spiral const phi = (Math.sqrt(5) - 1) / 2; // 0.6180339887 const goldenAngle = 360 * (1 - phi); // 137.507764° for (let n = 0; n < N; n++) { const theta = n * goldenAngle * Math.PI / 180; const r = Math.sqrt(n); // radius ∝ √n const x = r * Math.cos(theta); const y = r * Math.sin(theta); place_point(x, y); }

Stage 2 — The Packing Calculation

each point is a packing unit · the distance between neighbors is measured

The packing is measured. Each point is a packing unit. The distance to the nearest neighbor is computed for every point, and the packing density is calculated from the actual distances. The visual shows the computed packing, colored by the nearest-neighbor distance.

// Stage 2 — nearest-neighbor measurement function nearestNeighborDistances(points) { const distances = []; for (let i = 0; i < points.length; i++) { let minDist = Infinity; for (let j = 0; j < points.length; j++) { if (i === j) continue; const d = distance(points[i], points[j]); if (d < minDist) minDist = d; } distances.push(minDist); } return distances; }

Stage 3 — The Density

the packing density is computed from the measured distances

The density is computed. The packing density is the fraction of the area covered by the packing units. For the golden-angle spiral with radius ∝ √n, the density is uniform: each new point adds the same area, and the total area grows linearly with the point count. The visual shows the density histogram — the distribution of nearest-neighbor distances across the spiral.

// Stage 3 — density computation const distances = nearestNeighborDistances(points); const meanDist = mean(distances); const stdDist = stddev(distances); const uniformity = stdDist / meanDist; // lower = more uniform // For the golden-angle spiral, uniformity → 0 as N → ∞ // (the packing is asymptotically uniform)

Stage 4 — The Spiral Weave

the spiral is shown as a continuous weave · each turn advances by the golden angle

The weave is computed. The spiral is drawn as a continuous curve through the computed points. Each turn advances by the golden angle. The two families of counter-rotating spirals (the parastichies) are drawn in different colors — their counts are consecutive Fibonacci numbers.
